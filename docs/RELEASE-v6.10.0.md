## 四条原则详解

### 原则 1：结构多样性强制

**问题**：5 篇微头条全是"开场冲突→算账→反转→收尾追问"同款四段式流水线，遮住标题看不出是同一批。

**对策**：
- 6 种结构模板轮换使用
- 同批至少 2 种不同宏观结构
- 标准四段式 ≤ 3 篇/批
- 自检问题："遮住 5 篇标题，只看第一段，能看出是同一批吗？"

### 原则 2：伪造内容零容忍

**问题**：F1 事实分级管了"S 级可写/ C 级需标注"，但没有管"C 级数字写成 A 级表述凑字数"。

**对策**：
- 任何无来源数字不能出现在正文论据位置
- 数据空缺时只能用机制剥离/罗素翻转/跨时间外推补字，绝不编数字
- 封面图提示词的场景描述不能虚构原文没有的细节

### 原则 3：封面图风格词动态生成

**问题**：固定套同一组风格词（`cinematic photorealistic editorial`）正在变成新的统计默认。

**对策**：
- 按选题情绪基调动态选择风格词
- 6 类情绪基调对应不同的风格词组合
- 禁止 5 篇封面提示词风格词完全相同

### 原则 4：算账句式轮换

**问题**：每篇都用"我帮你算算这笔账"开头，语言模板化。

**对策**：
- 8 种算账起手式轮换
- 同批合计 ≤2 处（strict 模式单篇 ≤1 处）
- 自检："5 篇里'我帮你算算'出现了几次？"

## 校验脚本变更详情

### validate-persona.py — S1 检查项

```python
# 新增常量
_ACCOUNTING_OPENERS = [
    "我帮你算算", "咱们算算", "说句实在的", "先算笔账",
    "算一笔账", "算笔账", "来算算", "咱们来算",
]

# 检测逻辑（longest-first 去重）
_ACCOUNTING_OPENERS_SORTED = sorted(_ACCOUNTING_OPENERS, key=len, reverse=True)
acct_opener_count = 0
remaining = text
for p in _ACCOUNTING_OPENERS_SORTED:
    n = remaining.count(p)
    acct_opener_count += n
    remaining = remaining.replace(p, "", n)

# 通过阈值
acct_opener_pass = acct_opener_count <= 1
```

### validate-hotspot-batch.py — 新增两项检查

**算账起手式计数（全批）：**
```python
batch_opener_count = sum(a.count(p) for a in arts for p in _ACCOUNTING_OPENERS)
batch_opener_pass = batch_opener_count <= 2
```

**结构多样性检测：**
```python
STRUCTURE_MARKERS = {
    "数据冲击型": [r"^\d+[万亿亿千百十万块元%]", ...],
    "场景代入型": [r"^\d{4}年?\d{1,2}月?\d{1,2}日?", ...],
    "对话辩论型": [r"^(很多人|大家|网上|普遍认为|都说|常识)", ...],
    "机制剥离型": [r"^(这不是|表面看|本质上|底层|机制|逻辑是)", ...],
    "标准四段式": [r"我帮你算算.*听着没毛病", ...],
}
# 标准四段式占比 > 60% 直接拦截
```

## 与 Hallmark 原设计的差异

| 维度 | Hallmark（设计） | 热点刀锋（写作） |
|------|-----------------|-----------------|
| 执行机制 | 57 扇门硬拒绝 | 人工自检 + 脚本拦截 |
| 多样性单位 | 页面级宏观结构 | 段落级结构模板 |
| 伪造检测 | 量化声明自动标红 | F1 分级 + 人工判断 |
| 风格系统 | 21 主题 + Custom 模式 | 情绪基调 → 风格词映射表 |
| 自我批判 | 6 轴评分，<3 分自动修订 | 4 个自检问题，无自动修订 |

**本质差异**：Hallmark 是代码输出，可以硬拒绝；写作是自然语言，只能软约束。本原则的目标是把软约束尽量刚性化——能脚本化的脚本化，不能脚本化的人工自检。
