# 九边句式库与辣度校准

> 爆款刀锋的核心武器模块。写作全程必须调用以下句式，不是装饰，是骨架。

---

## 一、十五种句式（句式1-7为原七种，句式8-15为2026-08-31九边热文蒸馏新增）

### 句式1：本质剥离刀

```
公式：X不是在干A，是在干B。
效果：一句话剥开表象，直击本质
位置：打脸段 + 定音锤前置句
频率：≤1次/篇，每篇换靶子

示例：
农民不是在种地，是在给各种涨价打工。
尿素期货涨跌不是在定价，是在赌政策。
```

### 句式2：定性重锤

```
公式：这不是[对方用的词]，是[本质词]。
效果：釜底抽薪，把对手的语言体系直接掀翻
位置：打脸段
频率：≤1次/篇

示例：
这不是尿素价格上涨，是两套系统在各玩各的。
这不是市场波动，是有人在替你做主。
```

### 句式3：冷幽默刀

```
公式：[某概念/某现象] 听了这话，默默[动作/反应]。
效果：用类比制造黑色幽默，比直接骂更扎心
位置：任意段，打破严肃节奏
频率：可选

示例：
尿素期货的软件上，农民这个用户不存在。
35万手持仓，没有一笔是农民下的单。
```

### 句式4：递进王

```
公式：很明显，[表层事实]。[深层事实]。
效果：在读者以为已经结束时，再补一刀
位置：中段任意位置
频率：≤1次/篇，不要每篇结尾都用

示例：
很明显多空都在赌。但更关键的是——农民根本没有参与这场赌局的资格。
很明显尿素在涨。但更关键的是——涨出来的成本最后谁在扛。
```

### 句式5：自问自答

```
公式：你猜X？A？还是B？
效果：引导读者思考，同时给出暗示
位置：中段 + 结尾
频率：≤2次/篇，全文自问自答≤3处

示例：
你猜是农民赚了，还是期货老手赚了？
你猜城里人吃贵粮的时候，农民会因此多赚吗？
```

### 句式6：数字即幽默

```
公式：用数字排比制造压迫感，数字越大越荒诞
效果：不用加形容词，数字本身说出了一切
位置：贯穿全文，尤其打脸段
频率：不限

示例：
尿素期货持仓35万手。35万手。多少人在赌？
没有一个是农民。
```

### 句式7：身份重定义

```
公式：你不是X，你是Y。
效果：把读者的正面标签撕掉，换成更扎心的词
位置：暴风雪开场或打脸段
频率：≤1次/篇

示例：
你不是苹果的用户，你是苹果的资产。
你以为你是房东？你是终身股东。
```

---

### 句式8：概念造词型
```
公式：给[复杂现象]起个新名字：「XX型治理」/「XX效应」/「XX阶层」/「XX主义」。
效果：把一段机制压缩成一个"知识标签"，读者记住一个词就记住整篇文章
位置：机制剥离段 / 首次解释复杂概念处
频率：每篇1-2个，全文自造词≤2个
兑现规则：造词后必须用2-3句具体机制解释，否则变成黑话
示例：
这不是腐败，是"国家俘获"——一群有权的人和一群有钱的寡头，把公共机构当自家提款机。
这不是政策失误，是"洗劫型治理"——以前草原帝国打下一座城洗劫一空，现在没地方可洗劫，开始洗劫自己家。
这不是内卷，是"稳定系统惩罚失败"——每个位置都有人占着，失败者没有重新进入的通道。
```
**防AI味**：概念必须来自"机制剥离"而非"翻译专业术语"。先拆出底层逻辑，再命名；禁止先拿现成术语再套现象。

### 句式9：对仗双重定义
```
公式：X既是[A]，也是[B]。/ X往A开，也往B开。 / 一个负责[A]，一个负责[B]。
效果：一个句子把矛盾的两面钉死，对仗节奏自带记忆点
位置：核心论点 / 段落转折处
频率：≤1次/篇，每篇换矛盾对象
示例：
中国既是蒙古的饭碗，也是蒙古的靶子。
矿车往中国开，怨气也往中国开。
一个负责赚钱，一个负责做梦。
```
**与句式7（身份重定义）的区别**：句式7是"你不是X，你是Y"单向撕标签；本句式是把同一个主体的两个对立属性并列，制造撕裂感。

### 句式10：生活化类比点睛
```
公式：[抽象概念]就像[生活物件]，[一句话点破]。
效果：把宏观/专业的东西翻译成读者摸得到的东西，降低理解门槛
位置：解释复杂机制时
频率：每篇1-3个
示例：
资源国家的治理，就像手机没电时插着充电宝——嘴上说我独立，身体很诚实。
南非像是买了一台高配电脑，显卡内存硬盘全都有，结果系统天天蓝屏，电源还冒烟。
现代数学是一张艾尔登法环的开荒地图，没有大佬领路，你可能一辈子出不了新手村。
```
**类比选材原则**：只用读者日常见过的东西（充电宝/高压锅/物业/游戏/宿舍），禁止用读者没见过的概念解释另一个概念。

### 句式11：先立靶再拆靶
```
公式：[大众说法/普遍结论]。其实[不可能这么简单/原因怎么可能这么简单]。
效果：开场就建立"独立思考"人设，把大众结论当靶子，读者立刻好奇"那真相是啥"
位置：开场第1-3行
频率：≤1次/篇
示例：
网上常见说法是，蒙古疏远中国亲美国，所以才发展差。去了当地才发现，原因怎么可能这么简单。
很多人一聊南非，结论特别快：还不是黑人上台把国家搞坏了。这话倒也不能说错，但也没对哪去。
```
**与句式C（反常识开场型）的区别**：C 是给出"反常识事实"（临期牛奶其实还很新鲜）；本句式是"质疑大众结论并预告深度拆解"，不直接给答案。

### 句式12：事件升维成时代判断
```
公式：[具体事件]，背后其实是一个[时代级判断]。
效果：从小事件拔高到普遍规律，给文章加"思想重量"
位置：事件引入后 / 中段转折
频率：≤1次/篇
示例：
韩红让大家"给个面儿"被骂，背后有个很大的时代背景：几乎所有名人，声望都在快速消减。
明星带不动货，本质是权威从"终身职位"变成了"动态信誉"。
```
**升维纪律**：事件→判断之间必须有证据链（至少2个同类型现象佐证），禁止"一个现象+宏大结论"的硬拔。

### 句式13：历史埋雷-伏笔回收
```
公式：[多年前埋下的一颗雷]，[多年后准时爆炸]。
效果：用时间跨度制造宿命感，强化"因果必然"，读者看完起鸡皮疙瘩
位置：历史背景段 → 现状分析段
频率：可选（历史题材专用）
示例：
《班图教育法》把黑人的教育专门压低，这颗雷会在二三十年后准时爆炸——黑人拿到权力时，手上根本没有足够的医生、工程师可用。
```

### 句式14：反向治愈（珍惜体）
```
公式：你以为[已经很糟]？[更糟的群体]望眼欲穿的，就是[你现在的普通生活]。
效果：用更惨的处境反向治愈读者，把抱怨转为珍惜，结尾留正向情绪
位置：结尾段
频率：≤1次/篇，不要煽情
示例：
大家觉得生活无聊、没钱、没朋友，甚至觉得自己是社会底层。其实不知道，这下边还有十八层。欠债的、坐牢的，他们望眼欲穿的，就是普通人的普通生活。
```

### 句式15：质疑回应开场
```
公式：[看到这个说法/数据，我也觉得离谱]。一查却发现[很合理/竟然是真的]。
效果：先共情读者的怀疑，再反转，建立"我的结论经得起验证"的可信度
位置：开场第1-2行
频率：≤1次/篇
示例：
第一次看到"月薪七八千已经是绝大多数人一辈子达不到的高峰"也觉得是不是有点离谱，一查却发现很合理。
```

## 二（续）、痛点级专用句式

### 句式A：共情扎心型

```
公式：你以为X，其实人家早就把账算明白了。
效果：替读者算出他一直知道但不愿面对的数字
位置：中段核心论点
频率：≤1次/篇

示例：
你以为月薪一万算中产？扣完五险一金到手7800，
房租3000，通勤600，吃饭2000，剩下2200。
中产的门槛，比你想象的低得多。

你以为课外班一年花两万？你算算从幼儿园到高三，
光英语+数学+一门才艺，十五年下来至少30万。
你不是在投资教育，你是在给培训机构打工。
```

### 句式B：算账收尾型

```
公式：我帮你算了一笔账：[具体数字]。
效果：用具体数字收尾，比任何观点都有冲击力
位置：结尾替代追问
频率：≤1次/篇

示例：
提前还贷50万，省利息32万。听着不错对吧？
但你把这50万买国债，15年收益38万。
你不是在省钱，你是在亏6万的机会成本。

一个月通勤成本：地铁300，开车油费1200+停车800+保险均摊400=2400。
差价2100，一年25200，十年25万。
你每天堵在路上那40分钟，值25万吗？
```

## 二（续2）、认知级专用句式

### 句式C：反常识开场型

```
公式：[大众认知]。但真实情况是[反常识事实]。
效果：第一句话就制造认知冲突
位置：开场第1-2行
频率：≤1次/篇

示例：
超市临期牛奶，大家都觉得快过期了。
但真实情况是，保质期6个月的牛奶，
生产后第3个月就算"临期"。它还有3个月才过期。
你不是在买快过期的奶，你是在买打折的新鲜。

有机蔬菜比普通蔬菜贵3倍。
但真实情况是，国内有机认证的抽检率不到5%。
你多花的那两倍钱，买的不是安全，是一个标签。
```

### 句式D：冷知识递进型

```
公式：你知道[冷知识1]吗？还有更离谱的——[冷知识2]。
效果：层层递进制造"越挖越深"的阅读快感
位置：中段展开
频率：≤1次/篇

示例：
你知道超市里的"鲜榨果汁"大多是浓缩汁还原的吗？
还有更离谱的——有些"鲜榨"字样旁边写着"风味饮料"，
配料表第一位是水。你花了15块买了一杯糖水。

你知道酒店的"五星级"不是国家统一标准吗？
还有更离谱的——很多"五星"是酒店自己评的，
真正的五星级酒店全国不到800家。你住的可能是个"自称五星"。
```

### 句式E：反讽打脸型

```
公式：X本身不可怕，可怕的是你还当真了。
效果：先假装同意，再一巴掌拍醒，反讽感强
位置：中段转折或结尾
频率：≤1次/篇

示例：
小金豆涨价本身不可怕，可怕的是你还真觉得自己在"投资"。
100块一克买的金豆，回收价85，你还得自己搭上跑腿的时间。
你在理财，人家在赚你的理财焦虑。

房价跌了本身不可怕，可怕的是你还真以为自己能抄底。
跌了30%的房子，银行只批60%的贷款。
你以为在捡便宜，其实在帮银行消化库存。
```

## 二（续3）、一鱼三吃数据隔离规则

当一个热点需要拆成多篇内容时，三篇必须使用不同的数据源：

```
第1篇：用A组数据（行业/市场数据）
第2篇：用B组数据（消费者/社交媒体数据）
第3篇：用C组数据（历史对比/国际比较数据）
```

**核心原则**：观点方向可以一致（都在说同一个矛盾），但数据层必须隔离。
同一批读者会看到你的三篇内容——如果三篇用同一组数据，会觉得"又在嚼同一根甘蔗"。

**示例（小金豆主题）**：
- 第1篇（买入坑）：用期货价格、品牌溢价、回收折价数据
- 第2篇（心理篇）：用社交媒体讨论数据、消费者调查、小红书笔记数据
- 第3篇（变现坑）：用回收商报价数据、不同渠道价差、历史金价对比数据

## 二（续4）、新增句式使用纪律（2026-08-31 蒸馏合并）
> 以下纪律针对句式8-15（九边热文蒸馏新增），与原有句式共同组成武器池。
1. **5篇不重复原则**（延续 Pitfall#1）：新增8种与原有句式一起构成池子，连续5篇不能出现同一句式组合。
2. **概念造词兑现**：造词后2-3句具体机制解释，禁止只贴标签。
3. **类比选材**：只用读者日常物件，禁止"用概念解释概念"。
4. **事件升维须带证据链**：至少2个同类型现象佐证，禁止硬拔。
5. **数字镶嵌叙事**（替代"开头堆数字"）：数据带单位+对比，镶嵌在叙事中段；前300字窗口放1组"数字暴击"即可，正文再铺数据链。

## 三、禁用句式清单

### ❌ "说真的，并没有" — 全面禁用

用户反馈此句式在文章中显得突兀。所有"并没有"变体一律禁用。

替代方案：
- 开场悖论：直接用数字+反常识事实，不用"并没有"过渡
  - ✅ "谷歌每天85亿次搜索。91%准确率。每天1.53亿个错误答案。"
  - ❌ "你以为AI很准？并没有。"
- 中段打脸：用"这不是X，是Y"或"X不是在干Y，是在干Z"替代
- 认知颠覆：用"你猜"自问自答或"但更关键的是"递进替代

### ❌ "品品" — 已禁用

用户觉得这个词太轻飘。推荐替代：`掰开看看`、`撕开看看`、`算算`。

| "不可否认""众所周知""换言之" | AI套话 | 禁用 |

其余禁止词见统一清单。

## 四、三级辣度模型

> "辣"不是骂得更狠，是观点更出人意料。

### 辣度三级别

| 级别 | 方法 | 读者反应 | 示例 |
|------|------|---------|------|
| **微辣** | 描述现象 | 知道了 | "机器人便宜了，工人要失业了" |
| **中辣** | 重新定义 | 嗯？ | "这不是降价，是对你劳动力重新定价" |
| **特辣** | 反讽+死局 | 想反驳但说不出口 | "工人亲手造出了替代自己的机器，而机器人不会消费" |

### 辣度校准三问

判断辣度够不够：
1. 这个观点，读者是不是第一次听到？
2. 读完之后，会不会有人觉得"你胡说"但又说不出哪里不对？
3. 读者能不能一句话反驳？（能→正好，评论区会炸）

### 加辣路径

当用户说"辣度不够"时：
1. 写出大众观点
2. 问反面
3. 找到最扎心的那句话

不是加重语气，是换一个更反讽、更出人意料的切入角度。

## 五、过瘾版写作配方

当用户要求"更犀利/更过瘾"时使用：

```
1. 数据碾压开场 — 至少3组具体数字
2. 身份重定义 — 把读者的自我标签撕掉
3. 多层论证链 — 3-4个递进论点
4. 具体物件展开 — 每个论点配一个读者摸得到的东西
5. 冷幽默收尾 — 荒诞对比制造黑色幽默
6. 钱的追问 — 结尾追问到具体金额
```

过瘾版 vs 标准版：

| 维度 | 标准版 | 过瘾版 |
|------|--------|--------|
| 论点数 | 1-2个 | 3-4个递进 |
| 数据密度 | 每段1个 | 每段2-3个 |
| 定性力度 | "锁住你" | "你是资产" |
| 结尾追问 | 泛问 | 具体到钱 |
| 字数 | 300-500字 | 800-1200字 |

## 六、无署名铁律

任何引用、知识、框架、哲学概念，一旦吸收，就不再是"某某说的"，而是自己的思想。

❌ 禁止出现：
- "罗素100年前就说过……"
- "某哲学家认为……"
- "某本书里提到……"
- "古人云……"

✅ 正确做法：用自己的话重新表述，让思想本身说话。

**例外**：引用具体数据/统计时可注明来源（增加可信度）。

## Pitfalls

### 1. 九边句式复读机效应
每篇都用同一套句式，读者审美疲劳。5篇之间不能有重复套路。

### 2. MiMo安全拒绝
MiMo对"加辣度""调动情绪""煽动"等关键词特别敏感。遇到拒绝时换表述（"加辣度"→"观点更犀利一些"）。

### 3. Kimi-K3 触发微头条字数偏短复现（2026-08-03 实锤，教训#03） —  模型特性，非通用纪律

Kimi-K3 模型在微头条生成时，会倾向把"数字即幽默"和"算账收尾型"句式的数字压掉1-2组，导致正文偏短（低于200字下限）。

> ⚠️ 此为**模型怪癖**，仅在使用 Kimi-K3 时参考。核心字数红线（450-540字）对所有模型通用，见 hotspot-blade #43；Kimi-K3 专属应对措施归档在"模型注意事项"小节，prompt 不应把压缩行为硬编码为普适写作规则。

使用 Kimi-K3 时可选句式层面防御（非默认）：用"数字排比"替代"算账收尾"，把数字从结尾拆到正文中段，确保每个句式承载1组具体数字，模型压缩时也不破下限。

### 4. 句式库 vs 禁用句式冲突自查（2026-08-06 深度进化巡检）
"我帮你算了一笔账：[数字]"收尾型与"算算"替代词（"品品"禁用替代）存在重合风险——"算算"在部分上下文中会被误判为"品品"变体。**防御**："算算"仅在数字句中使用；观点收尾用"掰开看看"或"撕开看看"替代。
