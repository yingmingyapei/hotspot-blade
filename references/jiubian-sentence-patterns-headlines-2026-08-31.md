# 一、新增句式库（8 种，并入 toutiao-sentence-patterns/SKILL.md）

> 与现有 7 种犀利句式 + 痛点级 A/B + 认知级 C/D/E 不重复，全部来自九边热文实锤。

### 句式8：概念造词型 ⭐（最大新增武器）
```
公式：给[复杂现象]起个新名字：「XX型治理」/「XX效应」/「XX阶层」/「XX主义」。
效果：把一段机制压缩成一个"知识标签"，读者记住一个词就记住整篇文章
位置：机制剥离段 / 首次解释复杂概念处
频率：每篇1-2个，全文自造词≤2个
兑现规则：造词后必须用2-3句具体机制解释，否则变成黑话
示例：
这不是腐败，是"国家俘获"——一群有权的人和一群有钱的寡头，把公共机构当自家提款机。
这不是政策失误，是"洗劫型治理"——以前草原帝国打下一座城洗劫一空，现在没地方可洗劫，开始洗劫自己家。
这不是内卷，是"稳定系统惩罚失败"——每个位置都有人占着，失败者没有重新进入的通道。
```
**防AI味**：概念必须来自"机制剥离"而非"翻译专业术语"。先拆出底层逻辑，再命名；禁止先拿现成术语再套现象。

### 句式9：对仗双重定义
```
公式：X既是[A]，也是[B]。/ X往A开，也往B开。 / 一个负责[A]，一个负责[B]。
效果：一个句子把矛盾的两面钉死，对仗节奏自带记忆点
位置：核心论点 / 段落转折处
频率：≤1次/篇，每篇换矛盾对象
示例：
中国既是蒙古的饭碗，也是蒙古的靶子。
矿车往中国开，怨气也往中国开。
一个负责赚钱，一个负责做梦。
```
**与句式7（身份重定义）的区别**：句式7是"你不是X，你是Y"单向撕标签；本句式是把同一个主体的两个对立属性并列，制造撕裂感。

### 句式10：生活化类比点睛
```
公式：[抽象概念]就像[生活物件]，[一句话点破]。
效果：把宏观/专业的东西翻译成读者摸得到的东西，降低理解门槛
位置：解释复杂机制时
频率：每篇1-3个
示例：
资源国家的治理，就像手机没电时插着充电宝——嘴上说我独立，身体很诚实。
南非像是买了一台高配电脑，显卡内存硬盘全都有，结果系统天天蓝屏，电源还冒烟。
现代数学是一张艾尔登法环的开荒地图，没有大佬领路，你可能一辈子出不了新手村。
```
**类比选材原则**：只用读者日常见过的东西（充电宝/高压锅/物业/游戏/宿舍），禁止用读者没见过的概念解释另一个概念。

### 句式11：先立靶再拆靶
```
公式：[大众说法/普遍结论]。其实[不可能这么简单/原因怎么可能这么简单]。
效果：开场就建立"独立思考"人设，把大众结论当靶子，读者立刻好奇"那真相是啥"
位置：开场第1-3行
频率：≤1次/篇
示例：
网上常见说法是，蒙古疏远中国亲美国，所以才发展差。去了当地才发现，原因怎么可能这么简单。
很多人一聊南非，结论特别快：还不是黑人上台把国家搞坏了。这话倒也不能说错，但也没对哪去。
```
**与句式C（反常识开场型）的区别**：C 是给出"反常识事实"（临期牛奶其实还很新鲜）；本句式是"质疑大众结论并预告深度拆解"，不直接给答案。

### 句式12：事件升维成时代判断
```
公式：[具体事件]，背后其实是一个[时代级判断]。
效果：从小事件拔高到普遍规律，给文章加"思想重量"
位置：事件引入后 / 中段转折
频率：≤1次/篇
示例：
韩红让大家"给个面儿"被骂，背后有个很大的时代背景：几乎所有名人，声望都在快速消减。
明星带不动货，本质是权威从"终身职位"变成了"动态信誉"。
```
**升维纪律**：事件→判断之间必须有证据链（至少2个同类型现象佐证），禁止"一个现象+宏大结论"的硬拔。

### 句式13：历史埋雷-伏笔回收
```
公式：[多年前埋下的一颗雷]，[多年后准时爆炸]。
效果：用时间跨度制造宿命感，强化"因果必然"，读者看完起鸡皮疙瘩
位置：历史背景段 → 现状分析段
频率：可选（历史题材专用）
示例：
《班图教育法》把黑人的教育专门压低，这颗雷会在二三十年后准时爆炸——黑人拿到权力时，手上根本没有足够的医生、工程师可用。
```

### 句式14：反向治愈（珍惜体）
```
公式：你以为[已经很糟]？[更糟的群体]望眼欲穿的，就是[你现在的普通生活]。
效果：用更惨的处境反向治愈读者，把抱怨转为珍惜，结尾留正向情绪
位置：结尾段
频率：≤1次/篇，不要煽情
示例：
大家觉得生活无聊、没钱、没朋友，甚至觉得自己是社会底层。其实不知道，这下边还有十八层。欠债的、坐牢的，他们望眼欲穿的，就是普通人的普通生活。
```

### 句式15：质疑回应开场
```
公式：[看到这个说法/数据，我也觉得离谱]。一查却发现[很合理/竟然是真的]。
效果：先共情读者的怀疑，再反转，建立"我的结论经得起验证"的可信度
位置：开场第1-2行
频率：≤1次/篇
示例：
第一次看到"月薪七八千已经是绝大多数人一辈子达不到的高峰"也觉得是不是有点离谱，一查却发现很合理。
```

## 新增句式使用纪律
1. **5篇不重复原则**（延续现有 Pitfall#1）：新增8种句式与原有句式一起构成池子，连续5篇不能出现同一句式组合。
2. **概念造词兑现**：造词后2-3句具体机制解释，禁止只贴标签。
3. **类比选材**：只用读者日常物件，禁止"用概念解释概念"。
4. **事件升维须带证据链**：至少2个同类型现象佐证，禁止硬拔。
5. **数字镶嵌叙事**（替代"开头堆数字"）：数据带单位+对比，镶嵌在叙事中段，前300字窗口放1组"数字暴击"即可，正文再铺数据链。

# 二、新增标题公式库（8 种，并入 toutiao-viral-writing/SKILL.md「标题规则」）

> 现有「标题规则」仅 7 种风格（问句/金句/数据反差/短句/讽刺/直陈/时间跨度）。以下 8 种为九边热文实锤新增，全部含"反差/反常识/矛盾/悬念"要素，遵循 20-30 字、首行前 15 字压缩数字+冲突的既有规则。

### 公式A：悬念留白型
```
模板：[大事件] + 却 + [反常识结局]
示例：世界杯救国神话破灭！这个国家用两次冠军，却换来无尽的破产
效果：事件有热度，结局反直觉，读者想知道"怎么会这样"
适用：历史/国别/行业兴衰类长文
```

### 公式B：反差反讽型
```
模板：[道德褒义词] + 却 + [灾难结局]
示例：委内瑞拉：一片好心把国家带到了坑里
效果：用善意对冲恶果，反讽拉满，天然带观点争议
适用：政策/制度类反思文
```

### 公式C：两段式矛盾
```
模板：一边[A]，一边[B]（A与B构成内在撕裂）
示例：九边独家|又穷又有矿的蒙古国：一边靠中国吃饭，一边拿中国出气
效果：一句话揭示矛盾主体，好奇心拉满
适用：关系/身份冲突类
```

### 公式D：反常识定论
```
模板1：[主体]没有[预期结果] —— 稳定的系统没有"一战成名"
模板2：[结果] + [超出直觉的对比] —— 失败国家南非，穷人翻身后比之前那帮人还要差
效果：定论式金句标题，像一句话观点
适用：观点型/认知颠覆类
```

### 公式E：第一人称劝诫
```
模板：为啥我不建议你[做X]
示例：为啥我不建议你们去坐牢
效果：把明显的事说得像人生建议，自带反常识钩子+过来人身份
适用：科普/警示/经验类
```

### 公式F：反常识疑问
```
模板：[一个离谱的论断]+？
示例：月薪七八千已经是绝大多数人一辈子达不到的高峰？
效果：挑战读者认知，让人想点进去反驳
适用：数据类/社会认知类
```

### 公式G：热词+判断句
```
模板：所有的[X]+都在[Y]（X用当下网络热词）
示例：所有的"老登"都在退潮
效果：借流行语自带时代感，判断句制造态度
适用：热点/趋势观察类
```

### 公式H：人物传奇悬念
```
模板：一个[形容词]+的+[人物标签]
示例：一个差点被毁掉的天才
效果：悬念+悲剧感前置，人物故事自带传播性
适用：人物传记/命运故事类
```

## 标题公式使用纪律（并入既有标题规则）
1. **20-30 字**，首行前 15 字压缩「数字+冲突」（沿用既有规则）。
2. **同批轮换**（HB-05 延伸）：一批多篇时，反差/反讽类（A/B/C/D）占比 ≤60%，必须配 E/F/G/H 稀释。
3. **公式与内容匹配**：公式 A/B/C 适合长文（800-1200字）；E/F/G/H 微头条和长文通用。
4. **5篇不重复**：同一公式连续不超过2篇。
5. **避开雷区**：热词引用（G）需确认无歧义无敏感；人物类（H）不虚构人物。
