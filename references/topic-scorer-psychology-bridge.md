# 选题评分 × 心理模型桥接表

> 将 marketing-psychology 的心理机制注入 topic-scorer 五维评分。
> 评分不再靠感觉——每个维度对应明确的心理触发器。
> 版本：v1.0 (2026-07-29)

---

## 维度 → 心理机制映射

### 维度1：钱包距离（35%）

核心心理机制：**损失厌恶 + 当下偏见 + 零价效应**

| 分数 | 心理判定 | 触发机制 |
|------|----------|----------|
| 9-10 | "不点开会亏钱/少赚钱" | 损失厌恶（直接钱包威胁） |
| 7-8 | "知道会间接影响收入" | 当下偏见（近期收入冲击） |
| 5-6 | "可能对我的行业有影响" | 可得性启发（能想到案例） |
| 3-4 | "有钱人的事/离得远" | 地位-现状偏见（事不关己） |
| 1-2 | "跟钱无关" | 零相关（娱乐/体育） |

关键判断：读者能不能在 2 秒内算出"这事影响我多少钱"？算不出 → 低于 5 分。

### 维度2：反驳成本（25%）

核心心理机制：**现状偏见 + 权威偏见 + 承诺一致性**

| 分数 | 心理判定 | 触发机制 |
|------|----------|----------|
| 9-10 | "一句话戳破" | 现状偏见（读者已信A，说A→对） |
| 7-8 | "举个例子就能反驳" | 框架效应（换个说法就翻盘） |
| 5-6 | "需要查数据" | 可得性启发（能想到反例） |
| 3-4 | "普通人说不清" | 权威偏见（需要专家才能反驳） |
| 1-2 | "无法反驳/共识" | 现状偏见固化（如自然灾害同情） |

关键判断：读者刷到这条时，脑子里第一个反应是"不对吧"还是"确实如此"？后者 = 低反驳成本 = 高分。

### 维度3：物件锚点（15%）

核心心理机制：**单纯曝光效应 + 知识诅咒（反向） + 可得性启发**

| 分数 | 心理判定 | 触发机制 |
|------|----------|----------|
| 9-10 | "每天摸到的物件" | 单纯曝光（高频日常接触） |
| 7-8 | "知道但不常接触" | 可得性启发（认知可达） |
| 5-6 | "听过但没见过" | 可得性启发弱 |
| 3-4 | "需要解释一下" | 知识诅咒轻（作者需要降维） |
| 1-2 | "纯抽象概念" | 知识诅咒（读者无法想象） |

关键判断：读者能不看图就"看见"这个物件吗？能 = ≥7 分。

### 维度4：头条适配（15%）

核心心理机制：**模仿性欲望 + 社会认同 + 现状偏见**

| 分数 | 心理判定 | 触发机制 |
|------|----------|----------|
| 9-10 | "身边人都在聊" | 社会认同强（同事/家人已讨论） |
| 7-8 | "网上吵翻了" | 模仿性欲望（别人吵我也想掺和） |
| 5-6 | "行业内关注" | 社会认同中（圈层内热议） |
| 3-4 | "知识圈讨论" | 权威偏见（需要专家背书才吵） |
| 1-2 | "没人关心" | 零社会认同 |

关键判断：读者会不会觉得"不知道这事就落伍了"？会 = ≥7 分。

### 维度5：天然分裂（10%）

核心心理机制：**现状偏见（分裂双方） + 沉没成本 + 禀赋效应**

| 分数 | 心理判定 | 触发机制 |
|------|----------|----------|
| 9-10 | "两边都有道理" | 禀赋效应（各自坚守立场，不可调和） |
| 7-8 | "明显两派" | 现状偏见（已有立场，不愿改变） |
| 5-6 | "部分人有异议" | 沉没成本（投入的群体不愿退出） |
| 3-4 | "共识居多" | 社会认同（大多数人已站队） |
| 1-2 | "全民共识" | 现状偏见固化（无争议） |

关键判断：评论区会不会自己吵起来？不需要作者挑就会吵 = ≥7 分。

## 选题级别 → 心理模型优先级

不同级别的选题，调用的心理模型权重不同。

### 热点级（1-3小时抢占窗口）

核心目标：**CTR + 完读率**。读者处于"信息饥渴"状态。

| 优先级 | 模型 | 应用点 |
|--------|------|--------|
| P0 | 模仿性欲望 | 标题让读者觉得"别人都在聊这个" |
| P0 | 损失厌恶 | 封面文案暗示"不点开就亏了" |
| P0 | 单纯曝光 | 选题必须是近期高频接触的事件 |
| P1 | 锚定效应 | 标题首句给出意外数字，定读者预期 |
| P1 | 知识诅咒（反向） | 降维解释，让外行也能看懂 |
| P2 | 现状偏见 | 挑战读者"以为"的认知 |

**评分校准**：热点级选题的"钱包距离"权重可以降 5%，"头条适配"权重升 5%——热点自带流量。

### 痛点级（读者情绪密集）

核心目标：**互动率 + 完读率**。读者处于"情绪唤醒"状态。

| 优先级 | 模型 | 应用点 |
|--------|------|--------|
| P0 | 损失厌恶 | 损失框架："你正在失去什么" |
| P0 | 现状偏见 | 挑战"大家以为的对" |
| P0 | 承诺一致性 | 读者已有立场，文章加深它 |
| P1 | 锚定效应 | 用读者熟悉场景做锚 |
| P1 | 禀赋效应 | 让读者觉得"这事跟我有关" |
| P2 | 沉没成本 | 揭示已经投入的东西在流失 |

**评分校准**：痛点级选题的"反驳成本"权重升 5%（需要能吵起来），"天然分裂"权重升 5%。

### 认知级（深度分析）

核心目标：**完读率 + 转发率**。读者处于"求知"状态，有耐心。

| 优先级 | 模型 | 应用点 |
|--------|------|--------|
| P0 | 知识诅咒（反向） | 把复杂概念翻译成日常语言 |
| P0 | 首因效应 + 终点效应 | 开头定调，结尾留记忆点 |
| P0 | 现状偏见（挑战） | "你以为是A，其实是B" |
| P1 | 锚定效应 | 一个惊人数字开场定预期 |
| P1 | 峰终定律 | 高潮放在 60-70% 处 |
| P2 | 对比原理 | 用反差制造认知冲击 |

**评分校准**：认知级选题的"钱包距离"权重升 5%（得有数据支撑），"物件锚点"权重降 5%（允许适度抽象）。

### 微头条（300-500字）

核心目标：**前 30 字钩子 + 完读**。极速版热点级。

| 优先级 | 模型 | 应用点 |
|--------|------|--------|
| P0 | 损失厌恶 | 第一句就威胁/诱惑 |
| P0 | 模仿性欲望 | 前 30 字暗示"别人都在看" |
| P1 | 锚定效应 | 中间一个反差数字 |
| P1 | 现状偏见 | 推翻一个"大家都以为" |
| P2 | 峰终定律 | 结尾留钩子 |

## 使用方式

在 `topic-scorer` 的评分流程中，第 1 步之后插入心理模型判定：

```
第 1 步：五维度基础评分（原有流程）
第 1.5 步：对每个维度做心理机制判定（本表）
           - 钱包距离: 读者 2 秒内能算出钱的冲击吗？
           - 反驳成本: 读者第一反应是"不对吧"吗？
           - 物件锚点: 读者能"看见"吗？
           - 头条适配: 读者觉得"不知道就落伍"吗？
           - 天然分裂: 评论区会自己吵吗？
第 2 步：调整维度分（心理判定结果 vs 基础分取更保守值）
第 3 步：确定选题级别（S/A/B/C + 热点/痛点/认知/微头条）
第 4 步：按级别查本表的"心理模型优先级"，确认写作时该重点用哪几个模型
```

## 自检清单追加项

在 topic-scorer 原有自检清单之后追加：

```
心理模型校验：
□ 该选题至少触发 2 个 P0 级心理模型？
□ 标题是否应用了对应级别的心理模型（锚定/损失厌恶/模仿性欲望至少其一）？
□ 结尾是否留了"认知钩子"（峰终定律或知识诅咒反向应用）？
```
