# 写作 Anti-Slop 原则（移植自 Hallmark 设计思维）

> 来源：nutlope/hallmark（MIT，27K+ stars，Together AI）
> 迁移时间：2026-09-02
> 定位：补充热点刀锋已有纪律（HB-03/04/05/F1）的**执行力度盲区**，不是新增软规则。

---

## 核心原则：拒绝统计默认

Hallmark 的设计哲学——"强制 agent 拒绝 LLM 训练数据中最安全的统计平均值"——与热点刀锋 HB-05 同构，但执行更严：**不通过就拒绝输出**，不是"检查项后自评"。

**写作场景的三大统计默认（每批5篇必查）：**

| 统计默认 | 表现 | Hallmark 对应门 | 热点刀锋当前覆盖 |
|---------|------|----------------|----------------|
| 标题句式模板化 | 5篇里3篇以上用"不是A是B" | Gate 8（结构指纹重复） | HB-05 已有（>60%拦截） |
| 正文结构流水线 | 5篇全是"开场冲突→算账→反转→收尾追问"四段式 | 结构多样性强制 | **盲区**，无校验 |
| 封面图提示词固定化 | 5篇都套用同一组词（cinematic photorealistic editorial + 固定风格词） | Custom 模式动态生成 | 部分，风格词固定 |
| 算账句式重复 | 每篇都用"我帮你算算这笔账"开头 | 自我批判 Vari 轴 | 无校验 |

---

## 原则1：结构多样性强制（填补盲区）

同批5篇微头条必须满足：

- **至少2种不同的宏观结构**（不是标题句式不同，是段落节奏不同）
- **至少1篇不用"开场冲突→算账→反转→收尾追问"标准四段式**
- 同批收尾类型≥3种（已有收尾五型规则）

**结构模板库（轮换使用）：**

| 模板 | 结构 | 适用选题 |
|------|------|---------|
| 标准四段式 | 开场冲突→算账→反转→收尾追问 | 通用 |
| 数据冲击型 | 抛反常识数字→解释来源→个人账→社会账→追问 | 痛点级、有硬数据支撑 |
| 场景代入型 | 具体时间+地点+人物→正在发生的事→算账→判断 | 人物故事、事件类 |
| 对话辩论型 | 先摆大众结论→质疑→拆证据→给出自己的判断 | 争议性话题 |
| 机制剥离型 | 现象→底层机制→命名（概念造词）→推论→案例 | 深度分析、认知级 |
| 历史纵深型 | 当前事件→历史同类事件→规律提取→当下映射 | 国际/历史类，非敏感 |

**自检问题（写完后问自己）：**
> "如果把5篇文章的标题都遮住，只看第一段，能看出这是同一批吗？"
> 能 → 结构太雷同，换至少2篇的结构模板。

---

## 原则2：伪造内容零容忍（比 F1 更严）

Hallmark Gate 46 的严格程度比 F1 事实分级更高——**任何虚构数字，零容忍**。

**升级规则（整合进 HB-03）：**

- 不能为了凑字数把 C 级数字写成 A 级表述（如"据传"→"官方数据显示"）
- 数据空缺时，用**机制剥离/罗素翻转/跨时间外推**补字，**绝不编数字**
- 任何"约""大概""左右"后的数字，如果没有可核验来源，不能出现在正文论据位置
- 封面图提示词里的场景描述，不能虚构原文没有的细节（如原文没说"老人"，提示词不能写"白发老人"）

**与 HB-03 的关系：** HB-03 管"必须写数字"，这条管"没来源的数字不能写"。两者互补。

---

## 原则3：封面图提示词动态生成（防视觉模板化）

目前封面提示词固定套用同一组风格关键词，**本身正在变成新的统计默认**。

**改造方案：**

每次生成封面提示词时，根据选题的**情绪基调**动态选择风格关键词：

| 情绪基调 | 推荐风格关键词 | 禁用关键词 |
|---------|--------------|-----------|
| 冷峻/批判 | cinematic, editorial photography, chiaroscuro lighting, desaturated | warm golden hour, soft glow |
| 讽刺/反差 | split composition, visual irony, muted color grade, documentary style | celebratory, triumphant |
| 悲悯/沉重 | low-key lighting, documentary realism, desaturated, negative space | vibrant, saturated, high contrast |
| 讽刺/黑色幽默 | deadpan composition, flat lighting, observational documentary | dramatic, heroic, cinematic hero shot |
| 希望/治愈 | golden hour, soft natural light, warm color grade, intimate framing | cold blue, neon, high contrast |
| 悬念/悬疑 | chiaroscuro, moody lighting, shallow depth of field, isolated subject | wide angle, bright, evenly lit |

**固定风格关键词改为动态选择：**
- ❌ 旧：每篇都加 `cinematic photorealistic editorial, layered depth, muted/desaturated color grade`
- ✅ 新：根据情绪基调从上表选2-3个关键词，剩余位置补具体场景描述

**自检问题（生成封面提示词后问自己）：**
> "如果把这5篇封面图提示词去掉场景描述，只看风格词，能看出差异吗？"
> 看不出 → 换风格词，不要每篇都用同一组。

---

## 原则4：算账句式轮换（防语言模板化）

**禁止连续两篇用同一算账句式开头：**

| 句式 | 示例 |
|------|------|
| "我帮你算算这笔账" | 个人账开头 |
| "咱们掰开看看" | 机制拆解开头 |
| "说句实在的" | 判断先行开头 |
| "你以为……但实际是……" | 认知冲突开头 |
| "先算第一笔" | 多账并列表头 |
| 直接抛数字 | "500块。这是……" |

**自检问题（写完5篇后）：**
> "5篇里'我帮你算算'出现了几次？"
> ≥3次 → 换至少2篇的算账开头句式。

---

## 整合到校验流程

| 新原则 | 校验方式 | 检查项 |
|--------|---------|--------|
| 结构多样性 | 人工检查（或新增脚本） | 同批5篇≥2种宏观结构，标准四段式≤3篇 |
| 伪造内容零容忍 | 融入 `validate-persona.py` | F1 检查升级为：无来源数字直接拦截 |
| 封面图动态风格 | 人工检查 | 5篇封面提示词风格词不完全相同 |
| 算账句式轮换 | 融入 `validate-persona.py` | "我帮你算算"出现次数≤2次/批 |

## 与 Hallmark 原设计的差异说明

| 维度 | Hallmark（设计） | 热点刀锋（写作） |
|------|----------------|----------------|
| 执行机制 | 57扇门硬拒绝，不通过不输出 | 人工自检 + 脚本拦截 |
| 多样性单位 | 页面级宏观结构 | 段落级结构模板 |
| 伪造检测 | 量化声明自动标红 | F1分级 + 人工判断 |
| 风格系统 | 21主题 + Custom模式 | 情绪基调 → 风格词映射表 |
| 自我批判 | 6轴评分，<3分自动修订 | 4个自检问题，无自动修订 |

**本质差异**：Hallmark 是代码输出，可以硬拒绝；写作是自然语言，只能软约束。本原则的目标是把软约束**尽量刚性化**——能脚本化的脚本化，不能脚本化的人工自检。
