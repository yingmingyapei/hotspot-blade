# 选题评分手动校准指南

> 2026-07-29 实测：auto-score.py NLP 关键词匹配对大部分话题给出 B 级（4.x-5.x），
> 但手工用心理模型桥接表校准后，30 个话题中选出 5 个 S 级选题。
> 关键词匹配是快筛，心理模型判定才是终审。

---

## 为什么 auto-score 给分偏低

auto-score 的5维度评分依赖话题标题中的关键词匹配。当话题标题用词不直接触发钱包/反驳/物件字典时，分数自动归中到 4-5 分。

**实测偏差：**

| 话题 | auto-score 总分 | 人工校准分 | 偏差原因 |
|------|----------------|-----------|---------|
| 携程被罚51.79亿元 | 4.8 (B) | 8.2 (S) | 标题"被罚"未触发钱包字典，但51亿的锚定效应+损失厌恶极强 |
| 全款买房的人在变多 | 5.3 (B) | 8.5 (S) | "买房"触发中等，但"全款vs贷款"的反驳成本极高 |
| 黄金界爱马仕蒸发千亿 | 5.1 (B) | 7.8 (A) | "黄金"触发中等，但"千亿蒸发"的损失厌恶+锚定极强 |
| 小红书前员工期权被裁 | 5.0 (B) | 7.5 (A) | "期权"未触发字典，但"8天"时间锚点+损失厌恶极强 |
| 5元水饺4元面馆 | 4.8 (B) | 7.2 (A) | "水饺""面馆"未触发，但物件锚点极高（天天吃） |

## 手动校准三步法

### 第一步：跑 auto-score 做快筛（30秒）

```bash
python3 scripts/auto-score.py "话题1" "话题2" "话题3" ...
```

拿到每个话题的5维度分数。**不要只看总分**——看每个维度的分布。

### 第二步：对每个话题做心理模型判定（2分钟/话题）

用 `references/topic-scorer-psychology-bridge.md` 的维度→心理机制映射表，人肉问5个问题：

| 维度 | 校准问题 | 比 auto-score 多看到的 |
|------|----------|----------------------|
| 钱包距离 | 读者2秒内能算出"这事影响我多少钱"吗？ | 携程51亿→罚的钱最终谁买单，读者能算出自己分摊多少 |
| 反驳成本 | 读者第一反应是"不对吧"吗？ | 全款买房→"大家以为都在贷款，其实全款在变多" |
| 物件锚点 | 读者能不用看图片就"看见"这个物件吗？ | 5元水饺→每个人脑子里都有"一碗水饺"的画面 |
| 头条适配 | 读者觉得"不知道就落伍"吗？ | 携程→身边人都在聊的话题 |
| 天然分裂 | 评论区会自己吵起来吗？ | 全款vs贷款→两边都有道理，评论区必吵 |

**关键发现：** 钱包距离和反驳成本最容易低估。标题里没出现"工资""房贷""亏钱"等关键词时，auto-score 自动给低分，但实际话题可能直接打中读者的钱包。

### 第三步：算账视角验证（核心人设）

即使心理模型评分高，还要过最后一关——**能用"凡事算账的人"人设写吗？** 每个话题必须有一个"可算的数"：

| 话题 | 可算的数 | 算账框架 |
|------|---------|---------|
| 携程51亿 | 51亿÷携程用户=每人多少钱 | 罚了谁买单 |
| 全款买房 | 全款vs贷款30年利息差 | 你以为省了利息，其实... |
| 黄金爱马仕 | 千亿蒸发÷投资者=人均亏多少 | 买黄金真的保值吗 |
| 小红书期权 | 8天期权值多少钱 | 公司省了多少钱 |
| 5元水饺 | 5元水饺的利润 | 老板每天卖多少碗才够 |

**没有可算数字锚点的话题，即使心理模型评分高，也不适合"凡事算账的人"写。**

## 淘汰分类

| 淘汰原因 | 示例 | 替代建议 |
|----------|------|---------|
| 钱包距离低 | 日本地震、C罗被嘲讽、纽约出轨门 | 放弃，不做情绪稿 |
| 无算账锚点 | 女子高铁体制内、智驾蛄蛹者 | 适合做微头条但不适合深度算账 |
| 热度过期 | 三支一扶（知乎212万但已查2天） | 检查时间戳，错过窗口就放弃 |
| 专业门槛高 | 科技股大跌原因、Kimi K3 2.8万亿参数 | 头条读者看不懂，钱包距离虚高 |

## 完整的选题流程（v6.1 实测版）

```
1. 采集 → 列出所有话题（含来源热度+时间戳）
2. auto-score 快筛 → 淘汰 C 级（总分<4.0）
3. 心理模型人工校准 → 修正钱包距离+反驳成本分数
4. 算账视角验证 → 每个话题必须有可计算的数字锚点
5. 去重检查 → 同一事件只保留1个角度
6. 热度过期检查 → 超过6小时降级，超过8小时放弃
7. 输出 Top 5，每篇附算账切入点和数字锚点
```

**注意：** 步骤3和4是瓶颈。auto-score 可以批量跑30个话题，但人工校准平均每篇2分钟。这是当前流程中最耗时的环节，也是产出质量最高的环节——因为机器看不见"读者2秒内能不能算出来"。
