## 一、逐篇蒸馏

### 篇1《阿根廷：两次冠军换来无尽破产》
- **标题公式**：悬念留白型 —「大事件 + 却 + 反常识结局」，把"救国神话"与"无尽破产"两极对撞
- **开场**：时事切入型 — 从"这两天世界杯"借热点引出历史故事，读者带着当下热度进入历史纵深
- **结构**：时间线叙事（贝隆时代→军政府→1978买胜→马岛战争→米莱改革→2026轮回），首尾闭环
- **数据手法**：史实数字镶嵌叙事（3.5万吨粮食、5000万美元买一场6:0、通胀1000%、320万桶），数字全带单位，对比强烈
- **收尾**：回到当下（阿根廷再出征世界杯），"希望-崩溃-再希望的历史轮回里打转"一句点题闭环
- **核心洞察句**："他们国家真正的问题是'不稳定'——没人敢投资，资本只想跑，这比'福利高'更持久"

### 篇2《委内瑞拉：一片好心把国家带到了坑里》
- **标题公式**：反差反讽型 —「道德褒义词 + 却 + 灾难结局」，先立靶再拆靶
- **开场**：信源交代 + 核心论断前置 —"领导人和整个班子的每个决策都是高尚的，绝大部分人也支持，却一步步把国家带进坑里"，一句话立住全文矛盾
- **结构**：时间线 + 行业案例 + 反驳定论 + 对照国强化（1998分界→查韦斯→价格管制→国有化→印钱→恶性通胀→美元化→马杜罗被抓→**挪威对照**）
- **算账手法**："鸡蛋定价"把经济学讲成人话——"政府限价一打50块，但养鸡场成本饲料60+人工20+电费10=90"，成本vs定价具象算账，读者秒懂
- **数据链**：贫困率55%→32%、油价10→120美元、通胀40%→121%→254%→1087%→1000000%，用数字链条展示"从可控到崩盘"的恐怖曲线
- **收尾**：**先反驳大众结论**（"福利不能搞"是错的）→ 提炼真正教训（财政纪律/预算约束/央行独立/市场边界）→ 挪威对照点题

### 篇3《蒙古国：一边靠中国吃饭，一边拿中国出气》
- **标题公式**：两段式矛盾型 —「A动作 + B动作」制造内在撕裂感（吃饭/出气）
- **开场**：第一人称亲历 —"今年刚去了趟蒙古国，感触太深"，再"先抛大众观点后反驳"（网上说疏远中国才变差？不可能这么简单）
- **核心手法：概念造词** — 首创"洗劫型治理""提款机心态"等新词，给复杂现象贴标签，制造记忆点
- **金句密度极高**：
  - "中国既是蒙古的饭碗，也是蒙古的靶子"
  - "矿车往中国开，怨气也往中国开"（对仗）
  - "一个负责赚钱，一个负责做梦"（分工对仗）
  - "风从哪边吹不重要，锅往哪边甩才重要"（量子力学幽默）
- **类比库**：充电宝（嘴上独立身体诚实）、叛逆少年离家出走、家长看孩子（"行，路上注意安全，饭点记得回来"）
- **收尾升华**：从具体到抽象 —"那片土地到底是谁的土地？"把国家治理问题上升为哲学追问

### 篇4《南非：穷人翻身后比之前那帮人还要差》
- **标题公式**：反常识型 —「结果 + 超出直觉」，穷人翻身反而更差，天然引发争议
- **开场**：场景对比 + 高配电脑比喻 — 白人社区（"以为到了欧洲"）vs 贫民窟（"跌回真非洲"）；"买了一台高配电脑，结果系统天天蓝屏，电源还冒烟"
- **结构**：分节标题（##1历史→##2治理→##3治安→尾声）+ 机制剥离
- **核心手法**：
  - **历史埋雷叙事**（《班图教育法》压教育→二三十年后爆炸，伏笔回收）
  - **概念造词**："国家俘获""租金阶层（tenderpreneurs）""路径锁定"
  - **比喻连环**：高压锅盖子、房子物业（"维修队变成亲戚施工队"）、换了主人的笼子
- **金句**：
  - "国家俘获偷的是钱，否认科学偷的是命"（对仗+33万死亡数据）
  - "你已经知道哪条路是对的，但你回不去"（路径锁定）
  - "曼德拉帮它避开了地狱，但接下来的人干脆利索把车开到了坑里"（收尾）
- **收尾辩证**：反驳"黑人夺权搞坏国家"的简单归因 → 归因于治理失败 → 金句收尾

### 篇5《"黑化"法国队：雪中送炭却成社会噩梦？》
- **标题公式**：热梗 + 反差型 —「网络热词 + 却 + 反转定性」
- **开场**：时事钩子 — 从法国队世界杯成绩切入，抛争议问题
- **结构**：历史纵深（二战黑人打天下→戴高乐→法律禁肤色区分→劳工移民）→ 足球崛起归因（青训+天赋）→ 深层趋势推演
- **争议引爆手法**：主动抛出敏感观点，用质问句制造评论区大战——这是它 2112 条评论的来源
- **收尾**：趋势推演型 —"再过几代人，法兰西主流人种慢慢变成咖啡色"，留下想象空间
- ⚠️ **蒸馏提示**：此文借种族话题引爆争议，写作结构可借鉴（时事切入/历史纵深/趋势推演），但话题踩线、且文中部分族群论断缺乏严谨依据，**选题时需谨慎，不可照搬其立场**。

### 篇6《稳定的系统没有"一战成名"》
- **标题公式**：判断句 + 反常识型 —「XX没有XX」式定论，像金句一样好记
- **开场**：亲历 + 现象提问 —"去了趟韩国，突然把两个问题打通了：为什么新的大号越来越少了？"
- **核心手法：双层类比** — 平台（发现模式→维护模式→马太效应）⇄ 社会（增量扩张→存量分配），从小见大
- **概念造词**："稳定系统惩罚失败""未来不值得投资"
- **金句**："要么躺平要么赌博，两者本质上都是放弃对未来的投资"、"时间本身会形成最大的壁垒"（收尾点睛）
- **收尾转向**：压抑后给希望 — 从"一战成名极难"转向"缓慢成名"，落到"像个农民一样默默种地"，让读者带着正向情绪离开

### 篇7《为啥我不建议你们去坐牢》
- **标题公式**：第一人称劝诫型 —「我为什么不建议你做X」，把"坐牢"这件明显的事说得像一条人生建议，自带反常识钩子
- **开场**：前作钩子 + 信源交代 —"去年写过看守所爆款…读者出来了+联系上狱警读者才补齐素材"，用稀缺信源立住可信度
- **结构**：分节流程式（##1入监→##2监狱日常→##3霸凌与减刑→##4释放），猎奇科普+警示三合一
- **数据/细节**：吴某凡、李某铁看守所近两年；5+1+1 作息；一个月工资几十块；孙小果死刑12年半放出；郭文思9次减刑后再度杀人
- **手法**：
  - **极致场景还原**（画面感）："点名报数三部曲"、方便面料包是硬通货、小黑屋"以为过了一天其实才半小时"
  - **金句**："时间才是终极的刑罚"、"这下边还有十八层"
- **收尾升华**：从猎奇转到人生教育 —"欠债的、坐牢的，他们望眼欲穿的就是普通人的普通生活"，用底层惨状反向治愈读者

### 篇8《月薪七八千已经是绝大多数人一辈子达不到的高峰？》
- **标题公式**：反常识疑问句 —「一个看似离谱的论断+问号」，直接挑战读者认知
- **开场**：回应标题质疑 —"第一次看到也觉得离谱，一查却发现很合理"，先共情再反转
- **数据武器（全篇最重）**：
  - 中位收入三四千（赚4000就战胜一半人）
  - 北师大收入分配研究院：税后月入≥8000 占 12-15%，已是高收入阶层
  - 全国七八亿上班族，纳税仅 6000 万（<10%），且多是"年终奖被动触发"
  - 胡润财富报告：600万资产家庭全国仅 506 万户；京沪房产中位数约 400 万
- **结构**：数据立论 → 体验解释（"相对位置高≠购买力强"）→ 同温层/水池子概念 → 家庭三代积累（时代红利+体制内）→ 彩礼=三代积累 → **重点段**（七八千群体最易掉坑，FOMO）→ 范德彪翻红借势 → 收尾
- **金句**："工资叫流水，能带来安全感的是水池子"、"一个人正好是三代积累"
- **收尾**：劝诫回归理性常识、远离高杠杆

### 篇9《所有的"老登"都在退潮》
- **标题公式**：网络热词 + 判断句型 —「所有的X都在Y」，标题直接引用流行语，自带时代感
- **开场**：热点事件切入（韩红为《抓特务》拉票房被骂）→ 先表态（"我支持她，我还在定投她的慈善"并晒出 7 次 3493 元捐赠记录截图）→ 亮出时代洞察
- **核心手法：事件升维** — 从"韩红被骂"这一具体事件，拔高到"所有名人声望都在快速消减"的时代判断
- **结构**：事件 → 历史纵深（人上人传统→依附关系→去依附→仰视变俯视）→ 概念借用（**大教堂vs集市**：传统权威自上而下授予，现代权威靠用户"发现"）→ 延展（明星带不动货、权威从"终身职位"变"动态信誉"）→ 收尾辩证
- **金句**："你就是个摆摊的，你却把自己当主教"、"权威从终身职位变成了动态信誉"
- **收尾**：辩证升华 — 权威消减不是坏事，是平等思想+法治精神深入人心的必然结果

### 篇10《一个差点被毁掉的天才》（张益唐）
- **标题公式**：人物传奇型 —「一个X的Y」，悬念+悲剧感前置（差点被毁掉）
- **开场**：情感前置 —"我最喜欢的人，他的存在让我觉得这个世界还有另一种活法"，用个人情感拉近距离
- **结构**：人物传记时间线（1955出生→1969下乡→1978高考23岁上北大→1985普渡读几何→七年死磕雅克比猜想→论文因导师引理瑕疵翻车→决裂无推荐信→**赛百味打工七年**→1999新罕布什尔大学→52岁冲孪生素数→2012完成→爆火麦克阿瑟奖→2025加盟中大）
- **手法**：
  - **游戏类比**：艾尔登法环开荒地图=现代数学（新手村/Boss/凑碎片）
  - **圈子内幕**：推荐信制度、派系林立、天才必须大佬领路
  - **对比叙事**：王虹31岁/姜萍/姆巴佩成名链条，反衬张益唐"横空出世"的稀缺性
- **金句**："出发即目的，过程即结果"、"富贵是身外之物，贫穷也是"、"选择自己内心深处认同的道路，并且乐在其中，有没有结果可能并不重要"
- **收尾升华**：从张益唐延伸到韦神父亲死磕NS方程 + 当年明月"徐霞客游山玩水"典故，用人物故事抚慰普通人的失败焦虑，传递"另一种活法"

## 二、跨篇规律（可复用写作方法论）

### 1. 选题铁律
- **系列化叙事**：一个账号一个专栏（《世界沉浮录》），标签极度一致；1-6 篇"国家兴衰"、7-10 篇"社会现实+人生感悟"两条赛道互补
- **借热点切入**：世界杯（3篇借势）、韩红事件、时事新闻——热点只是门票，正文是深度分析
- **安全隔山打牛**：用"看别国"的姿势谈制度/治理/分配等敏感话题，远离国内敏感、不碰政策红线

### 2. 标题公式库（10篇共 8 种，全部含"反差/反常识/矛盾/悬念"）
| 公式 | 例 |
|------|-----|
| 悬念留白型 | "两次冠军，却换来无尽的破产" |
| 反差反讽型 | "一片好心把国家带到了坑里" |
| 两段式矛盾 | "一边靠中国吃饭，一边拿中国出气" |
| 反常识定论 | "穷人翻身后比之前还要差""稳定的系统没有一战成名" |
| 第一人称劝诫 | "为啥我不建议你们去坐牢" |
| 反常识疑问 | "月薪七八千…一辈子达不到的高峰？" |
| 热词+判断句 | "所有的'老登'都在退潮" |
| 人物传奇悬念 | "一个差点被毁掉的天才" |

### 3. 开场五法
- 时事切入借热度（篇1/篇5/篇9）
- 第一人称亲历"我刚去了趟X"（篇3/篇6/篇4）
- 先抛大众观点再反驳——"网上常见说法是…其实不可能这么简单"（几乎每篇，建立独立思考人设）
- 回应标题质疑——"我也觉得离谱，一查居然合理"（篇8）
- 情感前置——"我最喜欢的人"（篇10）

### 4. 内容手法库
- **概念造词/借用**：洗劫型治理、国家俘获、租金阶层、路径锁定、同温层、水池子、大教堂vs集市——每篇至少1个，形成"知识标签"
- **机制剥离**：不骂表象，拆底层博弈规则（委内瑞拉价格管制为何必然失败）
- **算账具象化**：鸡蛋成本vs定价、通胀数字链——把宏观经济学翻译成"人话+数字"
- **比喻连环**：充电宝/高压锅/房子物业/高配电脑/叛逆少年/艾尔登法环——全部来自生活场景
- **对照国强化**：挪威在3篇中反复出现（对照委内瑞拉/蒙古），用正面样本反衬失败样本
- **金句独立成段**：对仗句/幽默句/定性句，每篇3-5处，前后留白
- **极致场景还原**（画面感）：点名报数三部曲、方便面料包硬通货（篇7）
- **数据层层递进**：中位收入→权威机构比例→纳税人数→财富报告，四层数据叠加（篇8）
- **事件升维成时代判断**：韩红被骂→名人声望退潮（篇9）
- **个人信源立信**：狱警/出狱者（篇7）、读者素材（篇2）——"一手信源"是最大信任资产

### 5. 收尾五型
- 回到当下闭环（篇1"历史轮回"）
- 反驳定论+提炼真教训（篇2委内瑞拉）
- 压抑后给希望（篇6"缓慢成名"）
- 底层惨状反向治愈（篇7"这下边还有十八层"）
- 人物命运照见人生（篇10"另一种活法"）

### 6. 贯穿 10 篇的人设一致性
